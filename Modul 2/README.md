# mini.shop — Praktikum Modul 2

Aplikasi e-commerce sederhana (Mini Shopee) berbasis HTML, CSS, dan JavaScript native.

## Struktur

- `login.html` — halaman login
- `index.html` — katalog produk
- `css/login.css` — styling halaman login
- `css/index.css` — styling halaman katalog
- `js/login.js` — autentikasi dan session
- `js/catalog.js` — katalog, pencarian, filter, sorting, cart, modal, dan pagination
- `assets/` — folder aset lokal

## API

- Users: https://dummyjson.com/users
- Products: https://dummyjson.com/products

## Konsep JavaScript Modul 2 yang digunakan

External JavaScript + `defer`, `fetch()` + `async/await`, `try...catch`, DOM manipulation,
`localStorage`, array `map/filter/sort/reduce/slice`, closure untuk debounce,
dan event delegation pada product grid.
